# Sample data

`sample_ncrp_complaints.csv` is **made-up demonstration data** shaped like a cyber cell's NCRP / 1930 complaint
export. The complaint numbers start with `DEMO-`, the "Complainant Name" column holds placeholders, and several
suspect identifiers are the ones used by seller rings on the Charcha demo forum, so importing it shows cases being
linked to complaints. MuleWatch never imports the complainant column (there is no field to map it to).

Import it from **Complaints → Import complaints** while signed in as an Investigating Officer (`io`).
